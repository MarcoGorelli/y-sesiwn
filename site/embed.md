# Put a tune on your website

Any tune on Y Sesiwn can go on your own website, blog or class page: its
sheet music, with the player, so your visitors can listen and play along
without leaving your page. It's free, there's nothing to sign up for, and it
has no adverts.

## Getting the code

1. Open the tune on Y Sesiwn.
2. Choose its key, tempo and, if you like, tabs or holes: the code shows the
   tune that way.
3. Under the music, press **Share**, then **Put it on a website**.
4. Press **Copy the code**.

The code is a single line starting `<iframe`. Visitors to your page can
still change the key and tempo, and the tune's name opens it on Y Sesiwn.

## Pasting it in

Paste the code where you'd like the tune to be, in a block made for code
from other sites:

- **WordPress:** add a *Custom HTML* block. (On WordPress.com some plans
  don't allow it.)
- **Wix:** *Add*, then *Embed code*, then *Embed HTML*; choose *Code*.
- **Squarespace:** add a *Code* block (on some plans only).
- **Google Sites:** *Insert*, then *Embed*, then *Embed code*.
- **Moodle:** in the text editor, switch to HTML (the `</>` button). Your
  site's administrator may need to allow it.
- **Your own HTML:** put it where the tune should go.

If your website won't take code, send the tune's link instead: **Share**,
then **Copy link**.

## The size

The code is as tall as the tune when you copied it. On a narrower page the
music is laid out in shorter lines and needs more room: if you see a scroll
bar beside the music, make the number after `height=` bigger.

## Good to know

- The tune is always shown as it is on Y Sesiwn now: a correction made here
  shows on your page too.
- Y Sesiwn counts visits without cookies ([GoatCounter](https://www.goatcounter.com)),
  tunes shown on other websites included. Nothing else is collected.
